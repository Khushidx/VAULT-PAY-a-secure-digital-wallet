Tokenization & Storage Invariants

• Tokenized IDs Payment sources are represented by opaque tokens (tok_...), keeping card numbers off server disks.
• Zero CVV Policy Card security codes (CVV/CVC) are never stored, requested, or persisted under any circumstance.
• Masked Display Only non-sensitive identifiers and last 4 digits are retained (e.g. •••• 4242).
• AES-256-GCM AEAD Metadata is encrypted at rest using fresh 12-byte nonces and authenticated with 16-byte GMAC tags.
